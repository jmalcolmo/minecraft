# testMod

An early-game Fabric mod for Minecraft 26.1.2 focused on passive mob farming through craftable statues.

## Items

### Statue Core
Craft with iron ingots and a gold nugget (cross pattern). Carry it while killing passive mobs (cow, sheep, pig, chicken) to store energy — 10 per kill, up to 100 per mob type. Energy levels display in the item tooltip.

**Recipe:**
```
 I
IQI
 I
```
`I` = Iron Ingot, `Q` = Gold Nugget

### Mob Statue
A stone block that holds a Statue Core. While active it spawns nearby mobs proportional to stored energy and keeps them from wandering away.

**Recipe:**
```
SSS
SPS
SSS
```
`S` = Cobblestone, `P` = Carved Pumpkin

## Usage
1. Craft a **Statue Core** and carry it while killing cows, sheep, pigs, or chickens.
2. Craft a **Mob Statue** and place it.
3. Right-click the statue while holding the charged core to insert it.
4. The statue will begin spawning and attracting nearby animals.
5. Right-click empty-handed to retrieve the core.
